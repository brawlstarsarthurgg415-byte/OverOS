# OverVault x86_64 repository

This directory is reserved for OverOS x86_64 package archives and generated Pacman database files.

Expected generated files:

- `overvault.db.tar.zst`
- `overvault.db` (symlink generated by repo-add)
- `overvault.files.tar.zst` (when file-list database generation is enabled)
- `*.pkg.tar.zst`
- `*.pkg.tar.zst.sig`

Do not upload packages built for glibc-based distributions. Only publish packages tested against the OverOS musl environment.

Binary packages and generated database files will be added after the package build and signing pipeline is validated.
